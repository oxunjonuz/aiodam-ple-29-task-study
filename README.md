# AIODAM: exploratory solutions to 29 PLE development tasks

This is an independent exploratory study of the Physical-Engineering’s Last Exam (PLE) development set. The work was performed using the owner's AIODAM agent harness and DeepSeek V4.1 Flash, as reported by the agent. It is not an official PLE competition submission or an official leaderboard result.

The 48-page report describes the task deliverables, methods, limitations, and the agent's reported checks. The `solutions/` directory contains the 29 deliverables identified by the agent's ledger. Files were copied from the agent's workspace and checked against the sizes and SHA-256 prefixes in that ledger; `SHA256SUMS` records full hashes.

Some programmatic checks were run locally outside the official verifier container. Several checks-judge tasks lack a real model-judge evaluation, and all 14 rubric tasks lack such an evaluation. A stub or agent-written reader is not a model judge. Some work used visible verifier data or reference answers, and the report describes those cases. Consequently these results do not measure blind performance and should not be compared directly to official leaderboard results. The agent's reported scores and claims have not been independently audited.

The PLE dev tasks are by Google and contributors and are described as CC BY 4.0: https://huggingface.co/datasets/google/physical-engineerings-last-exam. This package may include adapted material from those tasks; see the original dataset and its terms. Competition code is separately available under Apache 2.0: https://github.com/google-research/ple.
